# QueueLess

A Virtual Queue Management System that allows users to join queues digitally and track their position without physically waiting in line.

## 📌 About the Project

QueueLess is a full-stack web application designed to manage virtual queues.

Instead of physically standing in a queue, users can join a queue online, receive a token, and track their position. Staff can manage the queue and call the next person when their turn arrives.

## 🎯 Objectives

* Allow users to join a virtual queue.
* Generate a token for each user.
* Allow users to track their queue position.
* Allow staff to manage waiting users.
* Allow staff to call the next token.
* Provide a simple and user-friendly queue management system.

### Staff

* View waiting tokens
* Call the next token
* Skip/remove a token
* Monitor queue status
